# Food Wars V1.2
Food Wars is a simple 2d sandbox game. This is the version 1.2 update.
## Getting Started
### Simple Installation
No build has been released yet.
### Run from Source
1) Clone the project to your device
2) Install 3rd party libraries
3) Run ```Food_Wars_V_1.2.py```

## How to Play
* Use WASD to move
* Use J to attack/break
* Use E to open inventory
* Use ESCAPE to pause

## Dependencies
* [Pygame-ce](https://github.com/pygame-community/pygame-ce)
* [opensimplex](https://code.larus.se/lmas/opensimplex)
* [Numpy](https://github.com/numpy/numpy)
* [esper](https://github.com/benmoran56/esper)
